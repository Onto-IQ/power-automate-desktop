# Authoring — เอกสารภายในทีมพัฒนาหลักสูตร

โฟลเดอร์นี้เก็บคู่มือสำหรับ **เขียน/แก้ Module** เท่านั้น

| สถานะ | รายละเอียด |
|--------|------------|
| Git | เนื้อหาส่วนใหญ่ **ไม่ขึ้น GitHub** (gitignore) — ผู้เรียนที่ clone จะไม่เห็น |
| ใครใช้ | ทีม Onto-IQ / วิทยากรที่ดูแลเอกสาร |
| ผู้เรียน | **ไม่แจก** และไม่ใส่ลิงก์จาก README หลัก |

## ไฟล์ที่ควรมีบนเครื่องผู้เขียน (local)

| ไฟล์ | หน้าที่ |
|------|---------|
| `WRITING-STYLE.md` | สไตล์ภาษาและโทนเอกสารผู้เรียน |
| `LESSON-TEMPLATE.md` | แม่แบบ `LESSON.md` |
| `HANDS-ON-LAB-TEMPLATE.md` | แม่แบบ `LAB.md` |

ถ้าเครื่องใหม่ยังไม่มีไฟล์เหล่านี้ ให้คัดลอกจากเครื่องทีม หรือจาก backup ภายใน — **อย่า commit กลับขึ้น repo สาธารณะ**

## เอกสารใน repo ที่ผู้เรียนใช้ได้

ดู [`shared/README.md`](../shared/README.md) และ [`modules/`](../modules/)
