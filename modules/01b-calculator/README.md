## วัตถุประสงค์

- Capture ปุ่มและช่องแสดงผลของ Calculator ด้วย UI Picker
- คลิกลำดับ `7 + 8 =` ด้วย **Click UI element in window** (ไม่ใช้พิกัดจอ)
- อ่านค่าจาก display เก็บในตัวแปร แล้วใช้ **If** ตรวจว่ามี `15`
- ปิด Calculator อย่างปลอดภัย
