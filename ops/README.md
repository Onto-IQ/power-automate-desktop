# Ops — เอกสารทีมสอน / Lab Hub (local)

โฟลเดอร์นี้เก็บคู่มือ **ในห้องเรียน** และสถานะเว็บ Lab Hub — ไม่แจกผู้เรียน

| สถานะ | รายละเอียด |
|--------|------------|
| Git | เนื้อหาส่วนใหญ่ **ไม่ขึ้น GitHub** (gitignore) — มีแค่ README นี้ |
| ใครใช้ | วิทยากร · TA · ทีมดูแล Lab Hub |
| ผู้เรียน | **ไม่แจก** |

## ไฟล์ที่ควรมีบนเครื่องทีม (local)

| ไฟล์ | หน้าที่ |
|------|---------|
| `TA-CHEATSHEET.md` | อาการที่เจอบ่อยและวิธีแก้เร็วในห้อง |
| `WEB-HUB-REQUESTS.md` | สถานะ/acceptance หน้า Lab Hub (เช่น catalog) |
| `*.local.md` | โน้ตเข้าถึงเซิร์ฟเวอร์ / SSH — เครื่องใครของคนนั้น |

ถ้าเครื่องใหม่ยังไม่มีไฟล์เหล่านี้ ให้คัดลอกจากเครื่องทีม — **อย่า commit กลับขึ้น repo สาธารณะ**
